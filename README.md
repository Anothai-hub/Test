# Column Base Plate Design (Streamlit)

เว็บแอปออกแบบแผ่นเหล็กรองฐานเสา (Column Base Plate) สำหรับเสาเหล็กรูปพรรณหน้าตัด H มาตรฐาน (มอก. 1227)
ที่รับ **แรงอัดตามแนวแกนอย่างเดียว** ตามแนวทางมาตรฐานการออกแบบอาคารเหล็กรูปพรรณ มยผ.
(หลักการคำนวณอ้างอิง AISC 360 ข้อ J8 และ AISC Design Guide 1) รองรับทั้ง **LRFD** และ **ASD**

## วิธีรัน

```bash
pip install -r requirements.txt
streamlit run app.py
```

## ขั้นตอนการคำนวณ

1. แรงอัดที่ต้องการ: LRFD `Pu = max(1.4D + 1.7L, 1.4D)` (แก้ตัวคูณได้) / ASD `Pa = D + L`
2. กำลังแบกทานคอนกรีต: `Pp = 0.85 f'c A1 √(A2/A1) ≤ 1.7 f'c A1` ; φc = 0.65, Ωc = 2.31
3. ระยะยื่นวิกฤต: `m = (N − 0.95d)/2`, `n = (B − 0.8bf)/2`, `λn' = λ√(d·bf)/4`, `l = max(m, n, λn')`
4. ความหนาแผ่นเหล็ก: LRFD `t = l√(2Pu / (0.9 Fy B N))` / ASD `t = l√(2 Pa Ω / (Fy B N))`, Ω = 1.67
5. รอยเชื่อมพอกขนาดต่ำสุด และสลักยึดอย่างน้อย 4 ตัว (ไม่รับแรงจากการคำนวณ)

หน่วย: แรง (ตัน/kg), ขนาด (mm/cm), หน่วยแรง (ksc)

## ไฟล์

- `app.py` — หน้าเว็บ Streamlit (ข้อมูลนำเข้า, รายการคำนวณ, แบบร่างแปลน, ดาวน์โหลดรายงาน)
- `base_plate.py` — ฟังก์ชันคำนวณ, ตารางหน้าตัด H, เกรดเหล็ก
